================================================================================
CHESS ANALYSIS PAYLOAD SCHEMA (UPDATED STATE-BASED APPROACH)
Endpoint: POST /api/analyze-game
Description: JSON payload containing full game PGN and deep client-side engine 
             evaluations generated via Stockfish 11 and Stockfish 17 workers.
================================================================================

1. ROOT OBJECT (AnalysisPayload)
--------------------------------------------------------------------------------
This is the top-level JSON object sent to the server when a game is analyzed.

* pgn (String): The raw Portable Game Notation string for the selected game.
* user_side (String): The color the searched user played ("white" or "black").
* analysis (Array of PositionAnalysis): A chronologically ordered array containing 
  the engine's assessment for every exact board position (ply) in the game, 
  starting from the initial starting position (ply 0).


2. POSITION OBJECT (PositionAnalysis)
--------------------------------------------------------------------------------
Each object in the "analysis" array represents the exact state of the board and 
engine calculations at that specific moment in time.

* ply (Integer): The 0-indexed ply number of the game (0 = starting position).
* move_played (String | Null): The Long Algebraic Notation (LAN) of the move 
  played to reach this position (e.g., "e2e4"). Null for the starting position.
* fen (String): The standard FEN string representing the exact board state at 
  this current ply.
* phase (Integer): The calculated game phase for the current board position.
* deep_eval (Number | String): 
  The deep engine's (Stockfish 17) evaluation of the CURRENT position. Formatted 
  as centipawns (e.g., 45) or forced mates (e.g., "M3"). Perspective is absolute 
  (Positive = White advantage, Negative = Black advantage).
* static_eval_trace (String | Null): 
  The raw text buffer containing Stockfish 11's static evaluation of the board 
  exactly as it stands at this current ply.
* top_lines (Array of EngineLine): 
  An array containing the deep engine's top 3 variations calculated from this 
  EXACT current board position.


3. TOP LINE OBJECT (EngineLine)
--------------------------------------------------------------------------------
Represents a single alternative Principal Variation (PV) branch generated by 
Stockfish 17 from the current position.

* rank (Integer): The engine preference rank of the alternative line (1 to 3).
* eval (Number | String): The deep evaluation of this specific alternative line.
* move (String): The very first LAN move of this alternative sequence.
* line (String): A space-separated string of LAN moves representing the engine's 
  predicted continuation for this alternative.

* leaf_static_eval_trace (String): 
  Stockfish 11's static evaluation buffer at the very end (leaf node) of this 
  alternative "line" continuation.
* leaf_fen (String): FEN for the leaf node position.
* leaf_phase (Integer): Game phase for the leaf node position.
